# 今日なに食べた？（Nani Tabeta）

いろんな味を楽しむための、食べたものの記録アプリ。
「これ前に食べたっけ？」に、その日の感想つきで答えます。

## 技術構成

- フロントエンド: Next.js 16 (App Router) / TypeScript / Tailwind CSS
- バックエンド: Spring Boot 3 / MyBatis / Spring Security
- データベース: MySQL 8.4 LTS
- 認証・ストレージ: Supabase Auth (Google OAuth) / Supabase Storage
